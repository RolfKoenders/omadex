# Third-party notices

## PokeAPI

This plugin fetches Pokémon data at runtime from PokeAPI:

- Upstream: <https://pokeapi.co>, source at <https://github.com/PokeAPI/pokeapi>
- License: BSD-3-Clause

No PokeAPI code or data is bundled with this repository. Everything is
fetched over the network on first lookup and cached locally afterward. No
API key or account is required.

## Pokémon sprites and artwork

Sprite and official-artwork images are fetched from PokeAPI's sprite
repository (<https://github.com/PokeAPI/sprites>) and cached locally after
first lookup. Pokémon character names, designs, sprites, and artwork are
